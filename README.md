# Marvel Watch Order 

## About the Project
This project is a web-based tracking application designed to help Marvel fans manage and keep tabs on their cinematic watchlists. The core functionality allows users to easily mark movies as completed with a single click, ensuring they always know where they left off in the franchise. To enhance user experience, the website features an instant search tool and dynamic sorting options, allowing users to arrange titles alphabetically or by release order. Additionally, clicking on any movie title redirects users directly to an external streaming platform, serving as a functional demonstration of web navigation and external linking.

## Technical Details
The visual aesthetics, user experience flow, and core design concepts of this application were completely ideated and conceptualized by me. Following this personal vision, the actual source code was built entirely using AI, embracing the modern "Vibe Coding" workflow. By leveraging AI to generate the front-end logic, the project effectively highlights how prompt engineering and rapid AI prototyping can bring an original, custom-designed interface to life using pure HTML5, CSS3, and JavaScript.

## Installation
To run this project locally, clone the repository using the following command:

```bash
git clone https://github.com
```

After cloning, navigate into the project directory and open the `index.html` file in any modern web browser.
